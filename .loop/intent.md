# Intent
<!-- WHY this work exists. Owned by the human. The agent must not silently change this file. -->

**Problem / user need:** Give people new to Loop Engineering a clear, visual, high-level explanation of how its iterative workflow works.

**Business outcome:** A self-contained single-page React app helps users understand the method and its practical principles.

**Non-goals:** Backend services, deployment, persistent user data, and changes to LoopKit command or instruction behavior.

**Constraints & standards:** Use the installed Node.js `v22.13.1`; choose React and build/test tooling with compatible declared engine requirements. Use accessible, responsive UI and focused unit tests for each application module.

**Stakeholders / who accepts the result:** The requesting user.
